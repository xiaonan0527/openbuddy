# 设计与实现基准

参考已实机核对的 WorkBuddy 任务工作台结构：左侧任务导航、居中的办公/开发/设计输入区、对话执行过程、右侧产物和文件面板、市场/调度/资料/设置分区。使用独立名称和原创代码，不引用原程序素材。

以产品信息结构和代码原生控件为设计基准，界面图标采用 Lucide。应用名称和标识独立设计，不包含原程序素材。

- 主背景：白与浅灰；强调色：深青绿。
- 字体：系统中文无衬线；控件使用明确字号、间距、可聚焦样式。
- 模式：固定侧栏 + 开放工作区；列表适用于任务/计划，适度使用资源卡片。
- 默认状态：空历史、真实配置状态；不填假任务、假连接、假收入或假成功率。
- 对话：显示真实模型文本、工具事件、批准/拒绝和实际文件产物。
- 小屏：折叠侧栏；主输入、审批和设置仍可操作。
- 限制：能力状态页明确列出云协作、支付、媒体、远控等需要外部服务的能力。

验证时分别核对布局、字号、配色、按钮/导航文案、空态、移动端、工具审批与文件预览，不将构建成功代替界面验证。
