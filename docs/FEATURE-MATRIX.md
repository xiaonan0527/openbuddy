# 功能覆盖与验证范围

OpenBuddy 是根据 WorkBuddy 功能分析报告独立实现的本地应用，采用自己的代码、提示词和界面。本文中的“已实现”表示本项目有实现代码；实际端到端验证以项目测试结果与交付说明为准。未移植原程序代码、图标、商标素材、腾讯账号或服务端接口。

功能对照基于 WorkBuddy 5.8.2 的可观察工作流程；本仓库不分发原应用、提取资源、个人分析记录或用户数据。

| WorkBuddy 功能族 | OpenBuddy 覆盖 | 当前限制 |
| --- | --- | --- |
| 任务与工作空间 | 新建任务、办公/开发/设计场景、历史会话、归档、删除、多个本地目录、搜索 | 暂无原版语音输入、消息分叉、Git worktree 自动管理 |
| Agent 执行 | 真实模型 API、流式输出、工具循环、停止任务、事件与审批、有限的真实专家咨询 | 主 Agent 可咨询独立只读专家；不含并发团队调度，不是腾讯 CodeBuddy 运行时 |
| 文件与命令 | 工作空间内目录/文本读写、经过批准的命令执行、附件上传与下载 | 文件工具阻止越界与符号链接；Shell 审批不是操作系统沙箱 |
| 专家与技能 | 12 个独立编写的内置技能、6 个专家、自定义增删改、技能启停、任务选用 | 不连接官方技能市场或订阅体系，不执行技能内任意代码安装 |
| MCP 连接器 | Streamable HTTP、stdio、工具发现、连接状态、Agent 工具调用审批 | 需要实际 MCP 服务；不含 OAuth 与官方服务凭据代管 |
| Word | 生成真实可编辑 DOCX；DOCX 正文转 HTML 预览 | 不是 Office/WPS 实时编辑器；预览可能损失复杂排版 |
| Excel | 创建 XLSX，设置基本表头格式，读取首个工作表预览 | 没有完整交互表格编辑、图表透视表设计或公式重算引擎 |
| PPT | 创建真实可编辑 PPTX，标题与正文布局 | 不含原版演示编辑器；PPTX 需下载到办公软件中查看 |
| 资料库 | 上传、列表、文件预览与下载，按名称/元数据查找 | 不含在线协作文档、智能表、向量数据库或全文检索 |
| 网页与设计 | Agent 生成 HTML、SVG、前端文件；HTML 隔离预览 | 不含 Ardot 分层设计器或 Miora 媒体画布 |
| 图片/视频/3D | 可通过用户连接的 MCP 扩展 | 没有预置媒体生成服务；不得以文本输出冒充成功生成 |
| 开发与发布 | 代码修改、审批执行构建/测试、文件成果 | 不含内置公网发布、云数据库或小程序发布托管 |
| 自动化 | 创建分钟间隔任务、启停、手动立即运行、关联运行任务 | 仅只读执行；进程必须开启，关闭期间不补跑；不含 RRULE/跨设备调度 |
| 微信/企微/飞书等远程助理 | 标明为外部能力 | 未连接，不发送消息，不模拟授权成功 |
| 多 Agent/专家团/A2A | 专家角色可以切换，consult_expert 可实际发起有限的独立分析请求 | 没有并发子 Agent、团队通信或 A2A 协议 |
| 团队与设备 | 标明为外部能力 | 无腾讯云助理、IM、端云同步和远程桌面后端 |
| 浏览器与电脑操作 | 可由用户接入对应 MCP 工具 | 未内置浏览器控制 runtime，也未请求录屏/辅助功能权限 |
| 模型与个性化 | 读取现有本机 provider；模型选择、连接测试、记忆、指令、明暗主题 | 不含本地模型下载管理；API 服务必须兼容所选协议 |
| 社区、分享与商业化 | 文件本地下载；能力状态如实展示 | 没有官方账号、积分、微信支付、社区或公网分享 |
| 安全与数据 | loopback 服务、本地持久化、密钥仅后端读取、文件路径限制、工具审批、只读自动化 | 不宣称具备企业隔离、加密同步、完整 DLP 或安全认证 |
| 桌面 | Electron 窗口、独立本地服务、应用打包配置 | 本地开发签名版本可能需 macOS 首次打开确认；不含自动更新服务器 |

## 数据与执行边界

- 密钥由后端读取本机现有配置，不通过 `/api/state` 发送给界面，不复制进项目。
- 模型 API 请求会发送当前任务、选定技能/专家指令、记忆及工具返回的相关内容。选择云端 API 不代表这些内容只存于本机。
- 文件工具只访问选定工作空间，受保护配置文件和符号链接不可读取。手动批准 Shell 后，命令以当前用户权限运行；这不等于容器或操作系统沙箱。
- MCP 连接操作可能启动用户填写的本地命令。连接前应确认命令来源，连接后的每次工具执行仍需批准。
- 自动化固定为只读，避免无人值守时等待审批或放宽权限；外部工具写入与命令执行不属于后台自动化能力。
- 项目不会将“尚未配置”“未测试”显示为执行成功。云服务、媒体生成、OAuth 等未实现项保留明确的能力说明。

## 建议验收场景

1. 设置内执行模型连接测试，确认当前地址与模型可用。
2. 新建测试任务，要求列出工作空间文件；检查真实工具事件和结果。
3. 要求创建 `hello.md`，批准工具后检查文件存在，刷新后仍能读取。
4. 创建 DOCX/XLSX/PPTX，下载后用对应办公软件打开，核对内容。
5. 添加自定义技能，选择后开新任务，确认输出遵循指令。
6. 创建只读自动化并立即运行，检查任务关联与结果；确认写入要求不能绕过只读模式。
7. 添加本地测试 MCP，手动连接，核对工具清单及批准/拒绝两条路径。
8. 重启应用，检查任务、资料和配置保留；执行中的旧任务应标为停止，不显示虚假完成。
